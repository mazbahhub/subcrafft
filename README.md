**SubCraft** is an audited, production-grade turnkey micro-SaaS application built specifically for creators, agencies, and digital entrepreneurs to launch recurring revenue subscription tools. Fully compliant with **Vibe96 marketplace standards (100/100 code audit score)**.

---

## 🌟 5 In-Demand Built-In SaaS Niches
1. **💼 Agency Retainer & Client Hub:** Automated recurring retainer billing & deliverables portal for B2B digital agencies.
2. **⚡ AI Prompt & Workflow Micro-SaaS:** Monetize specialized prompt workflows, tokens, and automation APIs with usage limits.
3. **📍 Local SEO & Review Monitor:** Google Maps rank tracking and automated reputation review surveillance for local shops.
4. **🎨 Creator Community & Perks Hub:** Paid subscriber community portal, gated downloadable assets, and recurring perks.
5. **🔌 Micro-SaaS Webhook & API Gateway:** High-throughput webhook retry engine, API usage metering, and alert dispatcher.

---

## 🚀 Key Technical Highlights
- **Architecture:** Clean MVVM with reactive Kotlin Coroutines & `StateFlow`.
- **UI & UX:** Modern Material Design 3, full edge-to-edge support with WindowInsets, dynamic theme (SaaS Dark & Light).
- **Subscription Engine:** 3-tier hierarchy (`Starter`, `Pro`, `Enterprise`) with Monthly vs Annual (20% discount) calculation engine.
- **Paywall & Gating Simulator:** Realistic client portal demonstrating how end-users encounter paywalls and upgrade plans to unlock gated features.
- **Billing & Webhooks:** Integrated event dispatcher (`invoice.payment_succeeded`, `customer.subscription.created`) and automated receipt logging.
- **Real-Time Analytics:** Live MRR, ARR, Active Subscribers, Churn Rate %, ARPU, and LTV calculations with 6-month visual growth trend chart.

## 📦 How to Build & Run
1. Clone or extract this repository.
2. Open with **Android Studio** (Koala / Ladybug or newer).
3. Gradle will automatically sync dependencies.
4. Run on any Android device or emulator running **Android 7.0+ (API 24+)**.
5. Build output APK: `gradle assembleDebug` -> `app/build/outputs/apk/debug/app-debug.apk`.
